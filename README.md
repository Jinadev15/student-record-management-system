# Student Record Management System

A console-based Student Record Management System developed using **C and C++** for organizing student information, processing records, and generating reports.

The project was built to apply fundamental programming concepts to a practical use case instead of keeping them limited to small standalone programs.

---

## About the Project

Managing student information manually can become difficult as the number of records increases. This project provides a simple command-line based approach for maintaining and working with student records.

The project is divided into two main components:

- `srms.c` — handles the core student record management functionality.
- `srms_report.cpp` — processes student information and generates reports.

The project uses **C for the main record-management functionality** and **C++ for the reporting component**.

The main purpose of the project is to understand how student information can be collected, stored, processed, and presented using fundamental C/C++ programming concepts.
